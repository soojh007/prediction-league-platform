Points breakdown

How each prediction is scored

Exact score Correct home score and correct away score 7 pts
Correct result Correct winner, or correctly predicted draw 3 pts
Correct goal difference Same margin as the actual result +1
Correct home goals Home team score matches exactly +1
Correct away goals Away team score matches exactly +1

Examples

If the actual result is Arsenal 2 - 1 Chelsea

Arsenal 2 - 1 Chelsea Exact score 7 pts
Arsenal 3 - 2 Chelsea Correct result and goal difference 4 pts
Arsenal 2 - 0 Chelsea Correct result and Arsenal goals 4 pts
Arsenal 1 - 0 Chelsea Correct result and goal difference 4 pts
Arsenal 2 - 2 Chelsea Correct Arsenal goals only 1 pt
Arsenal 0 - 1 Chelsea No match 0 pts
