# Product Notes

## Who This Is For

Primary customers:

- Office World Cup pools
- School/class competitions
- Friend groups
- Football fan communities
- Sports bars
- Clubs and societies

The paying user is usually the organiser, not every player.

## Main Pitch

Create a private football prediction league in minutes.

No spreadsheet.
No manual scoring.
No chasing people to predict.

## Key Features

- Private league invite code
- Automatic fixture import
- Score predictions
- Knockout predictions
- Automatic results and points
- League leaderboard
- Email reminders
- Admin announcements
- Mobile-friendly interface

## Differentiators

- Simple enough for casual users
- Customisable enough for organisers
- Works for different football competitions
- Supports knockout rounds properly
- Can be used by latecomers through separate round leaderboards

## Risks

- Do not position this as gambling.
- Avoid handling prize money directly at first.
- Keep admin payments as a hosting/platform fee.
- Avoid over-customising scoring rules before the MVP works.
